## API contracts

JSON errors have shape `{ error: string }`. Dynamic parameters use Next.js 15 promise params. `Choice<T>` is `{ value: T, confidence: number }`; domain objects refer to shared/types.ts.

| Route | Request | Response |
|---|---|---|
| `GET /api/pools` | Optional `?asset=<AssetClass>&protocol=<project>`; intersect exact matches | `{ pools: Pool[], verdicts: Record<string, Verdict>, asOf: string }`; verdict map scoped to returned pools; 503 if cache and fixtures cannot be read |
| `GET /api/pools/[id]` | Cached pool ID | `{ pool: Pool, verdict: Verdict \| null, history: { t: string, apy: number, tvlUsd: number }[] }`; ISO timestamps, last 90 days, 1-hour memory cache; stale history or `[]` on DeFiLlama outage; 404 unknown ID, 503 unavailable market data |
| `POST /api/intent` | `{ text: string }`, non-empty | `Intent` = `{ text, amount: number \| null, asset: string \| null, risk: Choice<'low' \| 'medium' \| 'high'>, horizon: Choice<'short' \| 'medium' \| 'long'>, assetPref: Choice<AssetClass \| 'any'> }`; Jev outage/offline retains parsed facts and returns confidence-zero manual choices; 400 invalid JSON/text |
| `POST /api/advise` | `{ intent: Intent }`; validates finite nonnegative amount/null, allowed choice values and confidence 0–1 | `{ recommendations: Recommendation[] }`, maximum 3; uses configured mirrors or null when undeployed; NOT_JUDGED fallback ranks real APY and explicitly warns risk is unassessed; 400 invalid input, 503 unreadable market data |
| `GET /api/scan/[address]` | Valid Monad EVM address, not ENS | `IdleReport` = `{ address, holdings: Holding[], idleUsd, potentialYearlyUsd, suggestions: Recommendation[], asOf }`; live RPC retries once then matching fixture fallback; OFFLINE/DATA_SOURCE=fixtures reads snapshot only; 400 `{ error: 'Not a valid Monad address' }`, 503 `{ error: "Couldn't read this wallet" }` |
| `GET /api/positions/[address]` | Valid Monad testnet owner address | `{ positions: Position[] }`; exact raw shares/assets as decimal strings, current APY/utilization bps, Guardian enabled state, latest complete judgment or null; empty deployment → `[]`; 400 invalid address, 503 RPC/read failure |
| `GET /api/watch/stream` | Optional `Last-Event-ID` header | `text/event-stream`; frames `id: <event.id>\ndata: <WatchEvent JSON>\n\n`; tails shared readEvents every 500ms without overlapping polls; abort/cancel clears timer; read failure emits `event: error` with `{ error: 'Could not read watch events' }` then closes |
| `POST /api/admin/stats` | `{ vault: address, apyBps: integer 0–65535, utilBps: integer 0–10000 }`; `x-admin-token` must equal non-empty server ADMIN_TOKEN; vault must be a configured mirror | `{ txHash: hex, block: decimal string, seconds: number }` only after operator confirms successful receipt; 401 missing/wrong/unconfigured token, 400 invalid stats/unapproved vault, 503 undeployed mirrors, 502 unconfirmed/failed transaction |

`OFFLINE=1` reads market fixtures without mutating DATA_SOURCE and disables history/Jev network calls; positions and admin remain real testnet operations. Secrets are read only by server route/library/operator code, never NEXT_PUBLIC_. Temporary smoke scripts/server/cache were removed/stopped; admin smoke kept the existing APY/utilization unchanged.
